# FoodVerse AI – Multimodal Food Intelligence Agent

A multimodal AI platform that analyzes food images, videos, audio and user
data to provide nutrition, freshness, hygiene, cooking and personalized
meal insights.

## Modules
1. Food recognition and nutrition analysis
2. Food freshness and spoilage detection
3. Restaurant hygiene and safety monitoring
4. Smart cooking assistance
5. Personalized meal planning

## Tech stack
ReactJS, FastAPI, Python, OpenCV, PyTorch, Meta Llama, Ollama

## Status
Work in progress. Environment setup complete.
